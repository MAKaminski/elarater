# ElaRater — brand kit v2 ("lobby daylight")

Same idea, different room. v1 was a machine room at night — black hoistway, amber
warning light, engraved steel plate, spec-sheet vocabulary. That's what read as
masculine: it wasn't the shapes, it was the *setting*.

v2 keeps the one thing that made v1 work — **the rating is displayed as a floor
indicator** — and moves it into the lobby at mid-morning. Warm daylight ground,
white ceramic panel, mid-century tile teal, rounded friendly type, plain-language
copy. Nothing about it now presumes who's riding.

## What changed

| | v1 | v2 |
|---|---|---|
| Ground | `#0B0C0E` near-black | `#FBF7F0` warm ivory |
| Lit color | Amber warning signal | Lobby teal + brass lantern |
| Type | Archivo, all-caps, engraved plate | Gabarito, sentence case, rounded |
| Shapes | Hard bezels, sharp triangles | Soft radii, rounded lantern |
| Copy | "Chime · Dwell · Jerk · Leveling" | "Smooth · Speedy · Spotless · Strangely musical" |
| Icon | Black panel | Solid teal — pops on any home screen, light or dark |

The spec-sheet vocabulary was the biggest offender. "Jerk" and "leveling" are real
ride-quality metrics, but they gate the joke behind knowing elevator engineering.
"Rides like butter" doesn't gate anything.

## Type

- Display: **Gabarito** 700 — rounded geometric, warm, sentence case
- Utility: **Figtree** 500/600 — labels and captions

Both free on Google Fonts. All type in the SVGs is converted to outlines, so the
files render identically anywhere with no font dependency.

## Usage rules

1. Two-tone wordmark stays: `Ela` ink, `Rater` teal. Flat one-color kills the pun.
2. Teal is the *lit* state. If it isn't scoring or calling for action, it isn't teal.
3. Brass appears once per composition — the up lantern. It's the warm spark, not a
   second brand color.
4. Clear space around the lockup = one lantern height. Minimum lockup width 180px;
   below that use the icon alone.

## Copy

- Headline: **Rate the ride.**
- Support: "Every elevator has a personality. Give it a score."
- Metric line: "Smooth · Speedy · Spotless · Strangely musical"
- Caption voice: plain, specific, a little funny. "Rides like butter." "Doors close
  like they're mad at you." "Plays smooth jazz, inexplicably."
